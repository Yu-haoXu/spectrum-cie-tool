Variable: wl (nm). Operators: + - * / ^. Functions include exp, log, sqrt, abs, sin, cos, tan, gauss(center,FWHM), lorentz(center,FWHM), step(edge), heaviside(x), shortpass(cutoff,width), longpass(cutoff,width), bandpass(low,high,width), and notch(center,bandwidth,depth,edgeWidth) (or notch(center,bandwidth,depth,fallWidth,riseWidth)). These functions generate the sample spectrum itself; the selected illuminant is applied separately during colorimetry. Each primitive profile such as step, lorentz, bandpass, and notch is intrinsically normalized to the 0–1 range. External coefficients are preserved during arithmetic. When Normalize final expression is enabled, the complete expression is evaluated first, negative values are set to 0, and only then the whole spectrum is divided by its positive maximum. Thus notch(...) + 100*step(...) keeps the 1:100 weighting before the final reflectance normalization.

In Intensity-aware mode, the illuminant intensity multiplier scales object XYZ before sRGB clipping: dim light gives darker RGB, while sufficiently strong light can drive all positive channels toward 255 (white saturation). Normalized / saturated rescales the linear RGB so its largest channel is 1, preserving the color appearance without absolute brightness.

    
The MATLAB export is self-contained: it embeds the currently loaded spectra, the active illuminant sampled on the wavelength grid, CIE observer data, and the current color/display settings. Running the .m file reproduces the calculations and opens the figures. It does not save files by default; set saveFiles = true inside the MATLAB script only when you want CSV/MAT/PNG/FIG outputs.

For reflectance/transmittance, the calculation uses sample spectrum × illuminant × CIE 1931 color-matching functions. The illuminant shape is normalized so a perfect diffuser has Y = 1 at intensity = 1, while the separate Intensity multiplier scales the resulting object XYZ and therefore its RGB brightness/exposure. CIE x,y remain unchanged by a uniform intensity scaling. For emission SPD, no illuminant multiplication is applied.

CIE 1931 2° standard observer and CIE D65 are implemented from standard tabulations/interpolation. Reference datasets: CIE 1931 colour-matching functions, DOI 10.25039/CIE.DS.xvudnb9b; CIE standard illuminant D65, DOI 10.25039/CIE.DS.hjfjmt59. sRGB uses the standard D65 XYZ→linear-sRGB matrix and IEC-style transfer function. This tool is intended for scientific visualization; monitor calibration and gamut limitations affect on-screen appearance.
